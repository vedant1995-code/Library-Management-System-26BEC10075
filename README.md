# Library-Management-System
 
 ## Project Description

The Library Management System is a Python-based project designed to manage library book records and borrowing activities. It allows students to explore available books from different categories, including Literature, Physics, and CSE.

The system also provides an admin login feature to check borrowing records. Students can select their preferred books and submit their name and registration number to record their borrowing details.

## Features

* Admin and Student login options.
* Password protection for admin access.
* Three categories of books:

  * Literature
  * Physics
  * Computer Science and Engineering (CSE)
* Display available books.
* Select books using serial numbers.
* Student details collection.
* Borrowing records management.
* Book borrowing period of 14 days.
* Simple and user-friendly interface.

## Technologies Used

* Python 3
* Basic Python concepts:

  * Conditional statements
  * Loops
  * Lists
  * Strings
  * User input and output
  * Variables

## How to Run the Project

1. Download or clone this repository.
2. Open the project in Python IDLE, VS Code, or PyCharm.
3. Run the Python file.
4. Select Admin or Student.
5. Follow the instructions displayed on the screen.

## Admin Login

The admin must enter the correct password to access borrowing records.

## Student Access

Students can:

1. Select a book category.
2. View available books.
3. Choose a book using its serial number.
4. Enter their name and registration number.
5. Confirm their book borrowing request.

## Project Objective

The main objective of this project is to understand the practical implementation of Python programming concepts by developing a simple library management system.
